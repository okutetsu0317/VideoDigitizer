# 独立開発方針

VideoDigitizerは、動画から2次元座標を取得する研究作業を支援する目的で独立して設計・実装されています。

## 開発上の原則

- 他社製品のプログラムコード、画像、アイコン、ロゴ、マニュアル文言を使用しない
- 他社製品の画面配置や装飾表現を再現することを目的にしない
- 特定製品の名称を、機能名、形式名、広告、比較表示へ使用しない
- 検証していない互換性、公認、提携、代替関係を表示しない
- CSV、JSON、動画、ピクセル座標など、一般的な技術用語と公開仕様を用いる
- 研究上一般的な計算方法は、出典と実装内容を区別できる形で記録する
- 第三者ライブラリのライセンスと著作権表示を配布物へ同梱する

## 配布前確認

配布ビルドでは `scripts/audit_independence.sh` を実行し、製品固有名や互換性を示唆する表現が公開物へ混入していないことを確認します。

この方針は法的判断を代替するものではありません。有償販売、組織導入、広範な広告を行う前には、名称、画面、実装、配布ライセンスについて知的財産を扱う専門家の確認を推奨します。
