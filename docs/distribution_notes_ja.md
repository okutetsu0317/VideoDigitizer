# VideoDigitizer 配布時の注意

この文書は、VideoDigitizerを研究仲間などに配布するときの注意点をまとめたものです。法的助言ではありません。無償配布でも著作権、商標権、特許権、第三者ライセンスの確認は必要です。配布範囲を広げる場合や組織で導入する場合は、弁護士または弁理士への確認を推奨します。

## 既存製品との関係

VideoDigitizerは独立して開発された研究補助ツールです。

既存の商用動作解析ソフトウェア、商標、ロゴ、画面デザイン、マニュアル、プログラムコードを利用・複製するものではありません。また、特定の既存製品との提携・公認・互換保証の関係はありません。

## 配布時に避ける表現

以下のような表現は、既存製品との関係や互換性を誤解させる可能性があるため避けてください。

- 特定の既存製品名を使った「互換」「仕様」「公認」「代替」
- 既存製品のロゴ、スクリーンショット、マニュアル文言の使用
- 既存製品から移植・派生したように見える説明
- 実際に検証していない解析ソフトとの読み込み保証

## 推奨する説明

配布時は、以下のような中立的な説明にしてください。

```text
VideoDigitizerは、動画をフレーム単位で確認しながら身体計測点を手動入力し、CSVとして出力するローカル実行型の研究補助ツールです。
```

```text
動画は外部サーバーへ送信されず、ユーザーのPC内の127.0.0.1で処理されます。
```

```text
本ツールは独立開発であり、既存の商用動作解析ソフトウェアとは提携・公認・互換保証の関係にありません。
```

## 最低限の配布チェック

- アプリ名、説明文、配布ページに他社製品名を使わない
- 出力形式は「CSV」などの一般的な表現にする
- 解析結果の最終確認は利用者の責任で行う旨を明記する
- 有償配布や広範な公開前に、商標・特許・ライセンスの確認を行う
- `scripts/audit_independence.sh` を実行し、製品固有名や互換性表現が混入していないことを確認する
- `scripts/audit_binary_licenses.sh` を実行し、FFmpeg、x264、x265が配布アプリへ混入していないことを確認する
- `technical_provenance_ja.md` と第三者ソフトウェアのライセンス文書を配布物へ同梱する
- `security_privacy_ja.md` と公開プライバシーポリシーを配布内容に合わせて更新する
- Googleログインを有効にする場合、Desktop OAuthクライアント、同意画面、公開ポリシーURL、承認済みログインボタンを使用する

## 独立性の記録

開発時は、要件、画面、データ形式、計算方法をVideoDigitizer自身の文書として記録してください。他社製品の画面、マニュアル、出力例を実装仕様として保存または転載しないでください。

一般的な研究手法を実装する場合は、製品名ではなく手法名と学術的な出典を記載し、特定製品との互換性を意味する説明を避けてください。

## Googleログインを配布するとき

GoogleログインはMacアプリ版だけで提供し、要求スコープは `openid profile email` に
限定します。OAuthクライアントIDを発行するGoogle Cloudプロジェクト、同意画面の
アプリ名、サポート連絡先、プライバシーポリシーURLは配布主体の情報と一致させてください。
ログインボタンはGoogle公式の承認済み素材を改変せず使用します。ログインは端末内の
利用者識別にだけ使い、動画・座標のGoogle Drive同期とは分けて説明してください。
Desktop OAuthのクライアント設定値は配布アプリから抽出可能です。クライアント
シークレットを機密情報やアクセス制御として扱わず、PKCEとstateを必須にしてください。
