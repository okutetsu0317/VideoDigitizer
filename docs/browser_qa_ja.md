# ブラウザ内の使い方QA

上部の「使い方QA」から別ページを開きます。動画のページはそのまま残ります。
質問を入力すると、使い方資料の関連項目を表示します。検索だけならAIモデルの取得は不要です。

## 端末内AI

「端末内AIを読み込む」→「取得して開始」を選ぶと、Qwen3 0.6Bの量子化モデルを
ブラウザ内で動かします。Ollama、Python、APIキー、Googleログインは不要です。
WebGPUとshader-f16が必要です。未対応の環境では資料検索を使用できます。
初回取得は約400MB、GPUメモリ目安は1.5GB以上です。実際の使用量と速度は端末によって異なります。

小型モデルの自由作文で架空の操作を案内しないよう、モデルには候補資料のIDだけを選ばせます。
アプリは許可されたIDを検証してから、その資料の原文を回答として表示します。
自由会話・動画の解析・画面操作をするAIではありません。資料の選び違いはあり得るため、
併記された参照資料も確認してください。各質問は独立して処理します。

## 動作負荷とデータ

- デジタイズ画面からQAのモデルやランタイムを事前読み込みしません。
- モデルは明示的に開始した場合だけ取得し、Worker内で推論します。
- 質問、動画、座標、プロジェクトを外部の推論APIへ送信しません。
- 外向き通信は、固定バージョンのモデルファイルのGETに限定しています。
- 初回取得先にはIPアドレス等の通常の通信情報が伝わります。
- 会話はページのメモリだけに置き、モデルはIndexedDBに保存します。
- 「中止」「AIを終了」、ページを閉じる・離れる操作でWorkerを停止します。
- AI実行時は端末のGPU・メモリを使用するため、同時に重い動画分析をしないでください。
- 「モデル削除」はQAモデルだけを削除し、プロジェクトの自動保存には触れません。
- ブラウザの容量制限や設定によってモデルキャッシュが消える場合があります。

完全なオフライン起動を保証するものではありません。ページやランタイムの再取得が必要な場合が
あります。ネットワーク不通でも、すでに開いているページでの資料検索は利用できます。

## 実装

`web_viewer/help-core.mjs`に確認済みの使い方21項目を収録しています。
質問は最大1000文字、候補資料は最大3件、モデルの出力は最大64トークンです。
小型モデルの検証で自由作文の回答が曖昧になったため、資料選択方式を採用しました。
実装・モデルのライセンスと固定リビジョンは`web_viewer/vendor/webllm/NOTICE.md`と
`help-config.mjs`を参照してください。
