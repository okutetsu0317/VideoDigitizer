# 使い方ガイド

従来の使い方QAは、モデル不要の静的な使い方ガイドに置き換えました。
上部の「使い方ガイド」から開けます。以前の `help.html` のリンクも同じページを表示します。

- 目次から20項目の説明へ移動できます。
- 機能名で検索できます。検索語は外部送信せず、保存もしません。
- 基本操作、4点法、保存、分析、困ったときの手順をまとめています。
- スクリーンショットは操作確認用サンプルで撮影しています。画像をクリックすると拡大できます。
- AIモデルの取得・実行はありません。JavaScriptが無効でも説明本文を読めます。
- 動画処理用の既存AI機能には変更を加えていません。

旧QAで取得したモデルがブラウザに残っている場合でも、このガイドは読み込みません。
プロジェクトの自動保存を守るため、サイトの保存データを一括削除する処理は行いません。

本文は `web_viewer/help-core.mjs`、構成は `scripts/build_help.mjs` にあります。
`node scripts/build_help.mjs` で静的HTMLを生成します。
